# Skill Name
mykenko-affiliate-policy-check

# Description
MYKENKOのアフィリエイト施策が景表法・薬機法・ASPルール・FTC規制に準拠しているかをチェックするSkill。アフィリエイターへの依頼文・掲載コンテンツ・報酬設計の適法性を審査します。

# Use Cases
- アフィリエイターへの依頼文が景表法・ステルスマーケティング規制に準拠しているか確認する
- アフィリエイト掲載記事の薬機法チェックをする
- アフィリエイト報酬設計が適切かチェックする
- ASP（アフィリエイトサービスプロバイダー）のガイドラインへの準拠確認

# Inputs
- `content`: チェック対象（依頼文・掲載記事・広告文等）（必須）
- `content_type`: 種類（affiliate_request / article / ad_copy）（必須）
- `target_market`: 対象市場（日本 / 米国 / その他）（デフォルト: 日本）

# Outputs
- コンプライアンスリスク評価
- 問題箇所と修正案
- チェックリスト（景表法・薬機法・ステルスマーケティング）

# Procedure

1. コンテンツ種類を確認する
2. 以下の観点でチェックする：
   - 広告表示（#PR等）の有無（ステルスマーケティング）
   - 薬機法に抵触する効能・効果の表現
   - 景表法に抵触する誇大表現
   - ASPガイドラインに抵触する表現（比較・誹謗中傷等）
3. 問題箇所をリストアップし修正案を提示する

# Rules
- 法的断定は行わない
- 「担当者または弁護士に確認を推奨する」と付記する
- ASPごとにガイドラインが異なることを考慮する

# Examples

## Example 1

入力：
```
content_type: affiliate_request
content: アフィリエイターの皆様へ。MYKENKOコラーゲンサプリをご紹介ください。
「飲んで3ヶ月でシワが消えた」「膝の痛みが治った」などの体験談を書いてください。
#PRは不要です。自然な口コミ風に書いてください。
```

出力：
```
コンプライアンスリスク: CRITICAL

問題箇所:
1. 「シワが消えた」「膝の痛みが治った」の表現を依頼
   → 薬機法に違反する医薬品的効能表現の指示。事業者が違反表現を依頼すること自体が問題
   → 削除必須

2. 「#PRは不要です」「自然な口コミ風に書いてください」
   → 景表法5条3号（ステルスマーケティング規制）の明確な違反
   → 商品提供・報酬がある場合は広告表示が義務
   → 削除・修正必須

修正案：
「MYKENKOコラーゲンサプリのご紹介をお願いします。
投稿には必ず「#PR」または「#AD」を含めてください（景表法遵守）。
商品の特徴：高純度コラーゲンペプチド配合、飲みやすいカプセル。
効能・効果の断定表現（「治る」「消える」等）はご使用をお控えください（薬機法遵守）。」

⚠️ この依頼文は現状のままでは送付しないでください。法務担当者への確認を強く推奨します。
```
