# Skill Name
mykenko-product-page-template

# Description
MYKENKOの商品ページ（LP・商品詳細ページ）を作成するためのテンプレートSkill。SEO最適化・薬機法準拠・構造化データを考慮したページ構成を提供します。

# Use Cases
- 新商品の商品ページ構成を設計する
- 既存商品ページのリライト計画を立てる
- 商品ページのコピーライティングガイドラインを適用する
- JSON-LD構造化データのテンプレートを生成する

# Inputs
- `product_name`: 商品名（必須）
- `product_category`: 商品カテゴリ（必須）
- `main_keyword`: メインキーワード（必須）
- `sub_keywords`: サブキーワードリスト（任意）
- `target_audience`: ターゲットユーザー像（必須）
- `product_features`: 商品の特徴・成分・使用方法（任意）

# Outputs
- ページ構成案（見出し構造H1〜H3）
- 各セクションのコピーライティングガイドライン
- メタタグ（タイトル・ディスクリプション）
- 薬機法注意事項
- JSON-LDテンプレート（Product Schema）

# Procedure

1. 商品情報とキーワードを確認する
2. ページ構成を以下のテンプレートで設計する
3. 各セクションに薬機法チェックポイントを付記する
4. JSON-LDテンプレートを生成する

# ページ構成テンプレート

```
## 推奨ページ構成

### H1: [メインキーワード含む商品名・キャッチコピー]
※ 薬機法NG表現を含まないこと

### セクション1: 商品概要・キャッチコピー
- 商品の特徴を端的に伝える（薬機法注意）
- ターゲットユーザーへの訴求ポイント

### セクション2: この商品が選ばれる理由（特徴・メリット）
- H2: [商品名]が選ばれる理由
- 3〜5個の特徴をアイコン付きで表示
- ※「〇〇に効く」ではなく「〇〇成分配合」で表現

### セクション3: 成分・原材料
- H2: 成分・原材料
- 全成分リスト
- 主要成分の説明（エビデンスベース）
- ※「治療効果」の表現禁止

### セクション4: 使用方法・摂取目安
- H2: 使用方法
- 1日の摂取量・タイミング
- 注意事項（妊娠中・授乳中・持病等）

### セクション5: お客様の声（レビュー）
- H2: お客様の声
- 実際のレビュー（#ステルスマーケティング確認済み）
- ※「〇〇が治った」という表現のレビューは掲載不可

### セクション6: よくある質問（FAQ）
- H2: よくある質問
- 商品に関するQ&A
- 薬機法・景表法への配慮を含む回答

### セクション7: 購入・注文
- CTA（行動喚起）
- 価格表示（景表法準拠）
- 送料・返品ポリシー

### フッター近辺: 免責事項
- 「本商品は医薬品ではありません」
- 「食品の機能・効果には個人差があります」
- 「疾病の診断・治療・予防を目的としたものではありません」
```

# Rules
- 薬機法チェック（mykenko-yakuki-check）を必ず実施すること
- 医薬品的効能・効果の断定表現は使わない
- 「No.1」「最高品質」等の表現は根拠がある場合のみ使用する
- レビュー掲載はステルスマーケティングチェック（mykenko-stealth-marketing-check）を通すこと
- 価格表示は景表法チェック（mykenko-keihyo-check）を通すこと

# Examples

## Example 1

入力：
```
product_name: MYKENKOコラーゲンサプリ
product_category: サプリメント
main_keyword: コラーゲン サプリ 飲む
target_audience: 30〜50代女性・肌のうるおいが気になる方
```

出力：
```
【ページ構成案】

H1: 飲むコラーゲンで毎日のスキンケアをサポート｜MYKENKOコラーゲンサプリ

<タイトルタグ>: 飲むコラーゲンサプリ｜毎日のスキンケアをサポート - MYKENKO（60文字以内）
<メタディスクリプション>: MYKENKOのコラーゲンサプリは高純度コラーゲンペプチドを使用。毎日の習慣に取り入れやすい飲みやすいカプセルタイプです。（120文字以内）

H2: MYKENKOコラーゲンサプリが選ばれる3つの理由
H3: 高純度コラーゲンペプチド配合
H3: 毎日続けやすい小粒カプセル
H3: 国内GMP認定工場製造

H2: 成分・原材料
H3: コラーゲンペプチドとは

H2: お客様の声
[ステルスマーケティングチェック必要]

H2: よくある質問

【薬機法注意事項】
⚠️ 「肌が若返る」「シワが消える」等の表現はNG
⚠️ mykenko-yakuki-check を必ず実施してから公開すること
```
