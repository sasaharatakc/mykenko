# Skill Name
mykenko-stealth-marketing-check

# Description
MYKENKOのアフィリエイト・インフルエンサー施策・口コミ施策がステルスマーケティング規制（2023年10月施行の景表法5条3号）に抵触しないかをチェックするSkill。

# Use Cases
- アフィリエイターへの投稿依頼文が適切な広告表示を求めているか確認する
- インフルエンサーのSNS投稿が「#PR」等の表示義務を満たしているか確認する
- 口コミキャンペーン・レビュー施策の設計が法令に準拠しているか確認する
- 社員・関係者のSNS投稿が適切かチェックする

# Inputs
- `content`: チェック対象のテキスト（投稿文・依頼文等）（必須）
- `post_type`: 投稿の種類（SNS / ブログ / YouTube / レビューサイト）（必須）
- `relationship`: 投稿者とMYKENKOの関係（アフィリエイター / インフルエンサー / 社員 / 一般消費者）（必須）

# Outputs
- ステルスマーケティングリスク評価
- 必要な広告表示の有無と表示方法
- 修正案
- 景表法ガイドライン参照

# Procedure

1. 投稿の種類と投稿者のMYKENKOとの関係を確認する
2. 以下の観点でチェックする：
   - 「#PR」「#AD」「#プロモーション」「#広告」等の適切な表示があるか
   - 「提供：MYKENKO」「MYKENKO様より商品提供いただきました」等の関係性開示があるか
   - 一般消費者の口コミに見せかけた事業者の宣伝になっていないか
3. 関係性がある場合は必要な表示方法を具体的に提示する
4. 依頼文がある場合は、依頼内容が法令に準拠しているか確認する

# Rules
- 2023年10月施行のステルスマーケティング規制（景表法5条3号）および消費者庁ガイドラインに基づいてチェックする
- 一般消費者の自発的な口コミとの区別を明確にすること
- 「断定的な法的判断はできない」旨を付記する

# Examples

## Example 1

入力：
```
post_type: Instagram
relationship: インフルエンサー（商品提供受けた）
content: このコラーゲンサプリ最近ハマってます✨ 肌の調子が本当によくなった気がする！ #コラーゲン #美容 #サプリ
```

出力：
```
リスク評価: NG（ステルスマーケティング規制に抵触する可能性が高い）

問題:
- 商品提供を受けた投稿であるにもかかわらず、「#PR」「#AD」「#プロモーション」等の広告表示がない
- 2023年10月施行の景表法5条3号ガイドラインにより、事業者から商品提供を受けたSNS投稿には広告表示義務がある

修正案:
「このコラーゲンサプリ最近ハマってます✨ 肌の調子が本当によくなった気がする！ #コラーゲン #美容 #サプリ #PR」
または
「このコラーゲンサプリ最近ハマってます✨（MYKENKO様よりサンプルいただきました）...」

⚠️ インフルエンサーへの依頼時は、広告表示を投稿に含めることを必須条件として契約に明記してください。
```

## Example 2

入力：
```
post_type: ブログ
relationship: アフィリエイター
content: 【本音レビュー】MYKENKOのプロテインを3ヶ月使ってみた結果... ※この記事にはアフィリエイトリンクが含まれます
```

出力：
```
リスク評価: OK（アフィリエイトリンク表示あり）

評価:
- アフィリエイトリンクの表示があり、広告としての関係性が開示されています
- ただし「本音レビュー」の内容が実際の使用に基づくものであることを確認してください

推奨:
- 記事冒頭または目立つ位置に表示することを推奨します（消費者が見つけやすい場所）
- 記事末尾だけでなく冒頭にも表示することが望ましいです

⚠️ 最終判断は担当者または弁護士に確認してください。
```
