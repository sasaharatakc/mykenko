# Skill Name
mykenko-keihyo-check

# Description
MYKENKOプロジェクトのコンテンツが景品表示法（不当景品類及び不当表示防止法）に準拠しているかをチェックするSkill。誇大広告・優良誤認・有利誤認の観点から審査します。

# Use Cases
- 「No.1」「最安値」「業界最高品質」などの表現が適切かチェックする
- 割引価格の表示（「通常価格〇〇円 → 特別価格〇〇円」）が景表法に準拠しているか確認する
- 比較広告の根拠が適切かチェックする
- 口コミ・レビューの使い方がステルスマーケティング規制に抵触しないか確認する

# Inputs
- `content`: チェック対象のテキスト（必須）
- `context`: コンテンツの種類（広告・商品ページ・SNS・メール等）（任意）
- `evidence`: 根拠資料の有無（あり / なし）（任意）

# Outputs
- チェック結果: `OK` / `要確認` / `要修正` / `NG`
- 問題箇所の一覧
- 修正案
- 景表法の根拠条文・ガイドライン参考

# Procedure

1. テキストを受け取り、コンテンツの種類を確認する
2. 以下の観点でチェックする：
   - **優良誤認（景表法4条1項1号）**
     - 根拠のない「No.1」「最高品質」「日本一」
     - 「医師が推薦」（具体的根拠なし）
     - 成分・効果の誇大表現
   - **有利誤認（景表法4条1項2号）**
     - 根拠のない「最安値」「最低価格」
     - 実際より有利に見せる価格表示
     - 二重価格表示の適正性
   - **ステルスマーケティング（2023年10月施行）**
     - 広告表示のない「広告記事」「案件投稿」
     - 「#PR」「#AD」「#プロモーション」の表示有無
   - **比較広告の根拠**
     - 根拠なき比較表現
3. 問題箇所をリストアップし、修正案を提示する
4. 総合チェック結果として出力する

# Rules
- 「景表法に違反しています」という断定判断は行わない
- 根拠資料があれば「No.1」「最安値」等の表現が使える場合があることを考慮する
- 必ず「最終判断は担当者または弁護士に確認することを推奨します」と付記する
- 2023年10月のステルスマーケティング規制（景表法5条3号）に対応すること

# Examples

## Example 1

入力：
```
context: 商品LP
content: 業界No.1の実績！日本で一番売れているコラーゲンサプリ。他社比較で最大50%OFF！
```

出力：
```
チェック結果: 要修正

問題箇所:
1. 「業界No.1の実績」
   - 問題: 根拠・出典が明示されていない優良誤認の可能性（景表法4条1項1号）
   - 修正案: 根拠調査会社名・調査日・調査対象を明示するか、表現を削除する
   - 例: 「〇〇調査（2024年△月、対象：□□）当社調べ」

2. 「日本で一番売れている」
   - 問題: 同上。「一番売れている」の根拠が必要
   - 修正案: 具体的な調査データを添付するか、表現を変える
   - 例: 「累計販売数〇〇万個突破（2024年〇月時点）」

3. 「他社比較で最大50%OFF」
   - 問題: 比較対象・比較時期・比較条件が不明。有利誤認の可能性（景表法4条1項2号）
   - 修正案: 「通常価格比50%OFF（当社通常価格〇〇円 → 特別価格〇〇円）」のように明示する

⚠️ 最終判断は担当者または弁護士に確認してください。
```

## Example 2

入力：
```
context: SNS投稿
content: このサプリ本当によかった！体調が全然違う。毎日続けています。 #健康 #サプリ
```

出力：
```
チェック結果: 要確認（ステルスマーケティングの観点）

問題:
- この投稿がMYKENKOから依頼されたものまたは商品提供を受けた投稿の場合、景表法5条3号（ステルスマーケティング規制）に抵触する可能性があります
- 2023年10月施行のガイドラインでは、事業者から商品を提供されたレビューには「#PR」「#AD」「#プロモーション」等の表示が必要です

修正案（依頼投稿の場合）:
「このサプリ本当によかった！体調が全然違う。毎日続けています。 #健康 #サプリ #PR」

⚠️ 最終判断は担当者または弁護士に確認してください。
```
