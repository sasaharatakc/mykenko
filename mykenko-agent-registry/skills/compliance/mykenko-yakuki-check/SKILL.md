# Skill Name
mykenko-yakuki-check

# Description
MYKENKOプロジェクトのコンテンツ（商品ページ・広告・SNS・アフィリエイト記事）が薬機法（医薬品医療機器等法）に準拠しているかをチェックするSkill。問題箇所の特定と修正案を提供します。

# Use Cases
- 商品ページのコピーが薬機法の誇大広告規制に違反していないか確認する
- サプリメント・化粧品・健康食品の効能表現が適切かチェックする
- SNS投稿・アフィリエイト記事の薬機法適合性を審査する
- 広告文・LPの公開前最終チェックを行う

# Inputs
- `content`: チェック対象のテキスト（必須）
- `product_type`: 商品カテゴリ（医薬品 / 医療機器 / 化粧品 / サプリメント / 健康食品 / その他）（任意）
- `target_country`: 対象国（日本 / 米国 / その他）（デフォルト: 日本）

# Outputs
- チェック結果: `OK` / `要確認` / `要修正` / `NG`
- 問題箇所の一覧（箇所・問題の説明・リスクレベル）
- 修正案（要修正・NGの場合）
- 参考法令・ガイドライン
- 専門家確認推奨の旨

# Procedure

1. テキストを受け取り、商品カテゴリと対象国を確認する
2. 以下の観点で問題箇所を抽出する：
   - **医薬品的効能・効果の断定表現**
     - 「治る」「治療する」「病気が治る」「症状が消える」
     - 「〇〇に効く」「〇〇を治療する」
   - **誇大表現・根拠のない優位性主張**
     - 「世界No.1」「最強」「完璧」（根拠のない場合）
     - 「医師も推薦」「病院でも使われている」（根拠のない場合）
   - **未承認医薬品の効能表示**
   - **特定疾病への効果の示唆**
     - がん・糖尿病・高血圧などへの効果の示唆
   - **体験談の誤用**
     - 「使ったら病気が治った」という体験談の掲載
3. 問題箇所をリストアップし、リスクレベルを判定する
4. 各問題に対して修正案を提示する
5. 総合チェック結果として出力する

# Rules
- 「薬機法に違反しています」「合法です」という断定的な法的判断は行わない
- 必ず「最終判断は法務・コンプライアンス担当者または弁護士に確認することを推奨します」と付記する
- 商品カテゴリ（医薬品・医療機器・化粧品・サプリメント）によって規制内容が異なることを明示する
- 化粧品は「効能の範囲」が厚生労働省により定められており、その範囲内であればOKであることを考慮する
- 保健機能食品（特定保健用食品・栄養機能食品・機能性表示食品）は別途規制があることを考慮する
- エビデンスに基づく記述（「〇〇成分が含まれています」）と効能断定（「〇〇に効きます」）を区別する

# Examples

## Example 1

入力：
```
product_type: サプリメント
content: このコラーゲンサプリを毎日飲めば、シワが消えて肌が若返ります。膝の痛みにも効果的で、関節の炎症を抑えます。
```

出力：
```
チェック結果: NG

問題箇所:
1. 「シワが消えて肌が若返ります」
   - 問題: 医薬品的効能（治療効果）の断定表現
   - リスク: 高
   - 修正案: 「うるおいのある肌を保つことを目指した成分配合」「肌のコンディションを整える」

2. 「膝の痛みにも効果的で、関節の炎症を抑えます」
   - 問題: 医薬品的効能（疾病の治療効果）の断定表現。食品への医薬品的効能表示は薬機法66条に抵触する可能性
   - リスク: 高
   - 修正案: この表現は削除を推奨。サプリメントでは関節・炎症への効果を表示できない

参考: 薬機法第66条（誇大広告等）
⚠️ 最終判断は法務・コンプライアンス担当者に確認してください。
```

## Example 2

入力：
```
product_type: 化粧品
content: ヒアルロン酸配合の保湿クリームです。乾燥した肌にうるおいを与え、なめらかな肌質に整えます。
```

出力：
```
チェック結果: OK（要確認）

評価:
- 「うるおいを与え」「なめらかな肌質に整えます」は化粧品の効能範囲内の表現です

要確認:
- ヒアルロン酸の配合濃度・由来について、適切な表示があることを確認してください
- 全成分表示が適切かどうか確認してください

⚠️ 最終判断は法務・コンプライアンス担当者に確認してください。
```
