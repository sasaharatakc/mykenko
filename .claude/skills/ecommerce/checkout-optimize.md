# /checkout-optimize — チェックアウト最適化

## 用途
MYKENKOのチェックアウトフローのCVRを最大化する。

## チェックアウト改善チェックリスト

### 入力フォーム
- [ ] 必須フィールドを最小化する（名前/住所/支払い情報のみ）
- [ ] オートコンプリートを有効にする（`autocomplete="shipping"` 等）
- [ ] エラーはリアルタイムバリデーション（フォーカスアウト時）で表示する
- [ ] 住所入力は郵便番号から自動補完する

### 信頼性シグナル
- [ ] SSL証明書バッジを表示する
- [ ] 支払いブランドロゴ（Visa/Mastercard等）を表示する
- [ ] 返品保証・配送保証を明示する

### 離脱防止
- [ ] カート放棄メールを設定する（1時間後・24時間後）
- [ ] 「保存して後で購入」機能を用意する
- [ ] 在庫残数・タイムセールの緊急性を表示する

### モバイル最適化
- [ ] ワンタップ購入（Apple Pay / Google Pay）を導入する
- [ ] 数値入力には数字キーボードを表示する（`inputmode="numeric"`）
- [ ] CTA ボタンは親指が届く範囲（画面下部）に配置する
