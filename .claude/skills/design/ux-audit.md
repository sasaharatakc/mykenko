# /ux-audit — UX監査フロー

## 用途
MYKENKOのUIを体系的に評価し、ユーザビリティ問題を特定する。

## ヒューリスティック評価（10原則）
ニールセンの10原則に基づいて評価する：

1. **システム状態の可視性** — ユーザーは今何が起きているか分かるか
2. **現実世界との一致** — ユーザーが使い慣れた言葉・概念を使っているか
3. **ユーザーの制御と自由** — 間違えたとき簡単に元に戻れるか
4. **一貫性と標準化** — 同じ操作が同じ結果をもたらすか
5. **エラーの防止** — ユーザーがミスしにくい設計か
6. **記憶ではなく認識** — 記憶に頼らず画面から判断できるか
7. **柔軟性と効率性** — 熟練ユーザーのショートカットがあるか
8. **美的・最小限のデザイン** — 不要な情報がないか
9. **エラー回復の支援** — エラーメッセージは分かりやすいか
10. **ヘルプとドキュメント** — 必要な時にヘルプにアクセスできるか

## 重大度評価
| レベル | 定義 | 対応 |
|------|-----|-----|
| 0 | 問題なし | - |
| 1 | 軽微な問題 | 余裕があれば修正 |
| 2 | 中程度 | 優先度を上げて修正 |
| 3 | 重大な問題 | 速やかに修正 |
| 4 | カタストロフィック | 即時修正必須 |
