# /email-flow — メールマーケティングフロー

## 用途
メールキャンペーン・ステップメールの設計から送信・分析までのフローを実行する。

## ステップメール設計
```
Day0: ウェルカムメール（登録完了・ブランド紹介）
Day2: 価値提供メール（役立つ情報・使い方）
Day4: 社会的証明メール（レビュー・事例）
Day7: オファーメール（限定クーポン）
Day14: リエンゲージメント（未購買者向け）
```

## 件名 A/Bテスト
- テスト対象: 件名のみ（1変数ずつ）
- テスト割合: 各20%、勝者を残り60%に送信
- 評価指標: 開封率

## 配信最適化
- 最適配信時間: 平日10〜11時、15〜16時
- 配信停止率が0.5%超えたら内容・頻度を見直す
