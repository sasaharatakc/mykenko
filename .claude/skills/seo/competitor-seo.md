# /competitor-seo — 競合SEO分析

## 用途
競合サイトのSEO戦略を分析し、自社の差別化機会・キャッチアップすべき領域を特定する。

## 分析手順
1. **競合サイト特定** — 検索結果で上位表示されている競合3〜5社を選ぶ
2. **キーワードギャップ** — 競合がランクインしているが自社にないキーワードを発見する
3. **コンテンツ分析** — 競合の上位ページのフォーマット・文字数・構成を確認する
4. **被リンク分析** — 競合の被リンク元を調査し、同様のリンク獲得機会を探す
5. **技術的優位性** — 自社と競合のページ速度・技術SEOを比較する

## 競合分析マトリックス
| 指標 | 自社 | 競合A | 競合B | ギャップ |
|-----|-----|-----|-----|------|
| 総ページ数 | - | - | - | - |
| キーワードランク数 | - | - | - | - |
| DR（ドメイン強度） | - | - | - | - |
| 月間推定トラフィック | - | - | - | - |

## 優先アクション
1. **Quick Win**: 競合が弱く自社が強いキーワードの最適化
2. **戦略的投資**: 競合が強いが重要なキーワードへの長期取り組み
3. **スキップ**: 競合が圧倒的に強く勝ち目のないキーワード
