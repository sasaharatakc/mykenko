# /serp-analysis — SERP（検索結果）分析

## 用途
特定キーワードの検索結果ページを分析し、上位表示するために必要なコンテンツ要件を把握する。

## SERP分析手順
1. **意図の特定** — 検索結果から検索意図（情報収集/比較/購買）を確認する
2. **上位ページ分析** — 上位3〜5ページの共通要素を特定する
3. **コンテンツ形式** — 記事/商品ページ/動画/FAQ等のどの形式が多いか
4. **特殊な検索結果** — Featured Snippet・PAA（People Also Ask）・ショッピング広告の有無
5. **差別化機会** — 上位ページが対応できていないニーズを発見する

## SERPフィーチャー別対策
| SERP機能 | 対策 |
|--------|-----|
| Featured Snippet | 質問→定義/リスト/表の構造化 |
| PAA（関連質問） | FAQセクションの充実 |
| ショッピング | 商品データフィードの最適化 |
| ローカル | Googleビジネスプロフィールの最適化 |
| 動画 | YouTube動画の最適化 |
