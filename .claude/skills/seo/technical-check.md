# /technical-check — テクニカルSEOチェック

## 用途
サイトのテクニカルSEO問題を素早くチェックし、対応が必要な問題をリストアップする。

## チェックリスト

### 速度・パフォーマンス
- [ ] PageSpeed Insights スコア（モバイル: 70以上を目標）
- [ ] LCP: 2.5秒以内
- [ ] INP: 200ms以内
- [ ] CLS: 0.1以内
- [ ] 画像の次世代フォーマット（WebP）使用
- [ ] 不要なJavaScriptの削除・遅延読み込み

### クロール・インデックス
- [ ] robots.txtに問題がないか
- [ ] XMLサイトマップの更新頻度
- [ ] noindexが必要なページに設定されているか
- [ ] canonicalが正しく設定されているか
- [ ] hreflangが必要な場合に設定されているか

### モバイル
- [ ] viewport metaタグの設定
- [ ] タップターゲットサイズ（44px以上）
- [ ] 水平スクロールが発生していないか
