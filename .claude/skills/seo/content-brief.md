# /content-brief — コンテンツブリーフ作成

## 用途
SEO記事の執筆前に構成・キーワード・要件をまとめたブリーフを作成する。

## ブリーフ項目
```markdown
## コンテンツブリーフ

### 基本情報
- 対象キーワード: 
- 月間検索ボリューム: 
- 検索意図: （情報収集/比較検討/購買）
- 目標ページURL: 

### コンテンツ要件
- 推奨文字数: X,000〜X,000字
- 対象読者: 
- 解決すべき疑問・課題: 

### 見出し構成（案）
H1: 
H2: 
  H3: 
H2: 

### 含めるべきキーワード
- 主要KW: 
- 関連KW: 
- LSIキーワード: 

### 競合コンテンツ参考
- 上位1位: URL
- 差別化ポイント: 

### 薬機法・コンプライアンス注意事項
（医療・健康コンテンツの場合のみ記載）
```
