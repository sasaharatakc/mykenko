# /seo-audit — SEO総合監査

## 用途
MYKENKOサイト全体のSEO問題を体系的に洗い出し、優先度付きの改善レポートを作成する。

## 監査項目

### テクニカルSEO
- [ ] Core Web Vitals（LCP/INP/CLS）の計測値
- [ ] モバイルフレンドリー対応
- [ ] HTTPS設定
- [ ] サイトマップの存在と正確性
- [ ] robots.txtの設定
- [ ] 404・リダイレクト状況
- [ ] 構造化データの実装

### オンページSEO
- [ ] タイトルタグの最適化（重複・長さ・キーワード）
- [ ] メタディスクリプションの有無と質
- [ ] H1〜H3の見出し構造
- [ ] 画像alt属性
- [ ] 内部リンク構造

### コンテンツ
- [ ] 主要キーワードのランキング状況
- [ ] コンテンツギャップ（競合が持つ自社にないコンテンツ）
- [ ] 薄いコンテンツ（300文字以下）のページ

## 出力フォーマット
```
## SEO監査レポート
### 緊急対応（Critical）
### 要改善（High Priority）
### 改善推奨（Medium）
### 維持・継続（Low）
```
