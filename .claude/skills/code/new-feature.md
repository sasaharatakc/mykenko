# /new-feature — 新機能実装フロー

## 用途
MYKENKOに新機能を追加する際の標準実装フローを実行する。

## 実装ステップ
1. **要件確認** — 機能の仕様・受け入れ条件・対象ユーザーを確認する
2. **設計** — API設計・DB設計・コンポーネント設計を行う
3. **バックエンド実装** — Laravel APIエンドポイント・ビジネスロジック・マイグレーション
4. **フロントエンド実装** — Next.jsページ・コンポーネント・API連携
5. **テスト作成** — ユニットテスト・統合テストの実装
6. **コードレビュー** — セキュリティ・品質・パフォーマンスのチェック
7. **動作確認** — 開発環境での動作テスト

## チェックリスト
- [ ] マイグレーションは後方互換性があるか
- [ ] APIは認証・認可が適切に設定されているか
- [ ] 入力値バリデーションが実装されているか
- [ ] エラーハンドリングが適切か
- [ ] テストが書かれているか（カバレッジ基準: 80%）
- [ ] 薬機法・コンプライアンス問題がないか

## 関連Agent
- laravel-engineer（バックエンド）
- nextjs-engineer（フロントエンド）
- qa-engineer（テスト）
- security-engineer（セキュリティレビュー）
