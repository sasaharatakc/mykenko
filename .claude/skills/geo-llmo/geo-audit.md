# /geo-audit — AI検索（GEO）監査

## 用途
Google AI Overview・Perplexity・ChatGPT検索でのMYKENKOのコンテンツ掲載状況を監査する。

## 監査対象
- Google AI Overviewへの掲載状況
- Perplexityでのブランドメンション
- ChatGPT・Geminiでの引用状況

## AI検索対応チェックリスト
- [ ] 質問形式のコンテンツ（FAQページ）が存在するか
- [ ] 明確な定義・説明文がページ上部にあるか
- [ ] エンティティとして認識されるブランド情報が整備されているか
- [ ] 権威サイトからの被リンク・メンションがあるか
- [ ] 構造化データが正しく実装されているか
- [ ] コンテンツが引用しやすいファクト・数値を含むか

## AI引用されやすいコンテンツ特性
1. 明確な答えが冒頭にある（Bottom Line Up Front）
2. 信頼できる情報源へのリンクがある
3. 専門家・著者情報が明記されている
4. 最終更新日が記載されている
