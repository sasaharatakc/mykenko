# /video-script — 動画台本作成フロー

## 用途
YouTube・TikTok・InstagramリールなどのSNS動画台本を構造的に作成する。

## 台本作成ステップ
1. **目的定義** — この動画で視聴者に何をしてほしいか（購入/登録/シェア）
2. **ターゲット設定** — 誰に向けた動画か（悩み・属性・視聴環境）
3. **フック設計** — 最初の3秒で何を言うか
4. **本編構成** — 価値を届ける核心コンテンツを構成する
5. **CTA設計** — 動画の最後に何を促すか

## プラットフォーム別台本フォーマット

### TikTok / Reels（60秒以内）
```
[0-3秒] フック: 「〇〇を知らないと〜」
[3-10秒] 約束: 「この動画で〇〇がわかります」
[10-50秒] 本編: [ポイント①②③]（各10秒以内）
[50-60秒] CTA: 「フォローして〇〇をチェック」
```

### YouTube（5〜10分）
```
[0-30秒] フック + 約束
[30秒-1分] 自己紹介 + 信頼構築
[1-8分] 本編コンテンツ（2〜3つのセクション）
[8-9分] まとめ
[9-10分] CTA + 次の動画への誘導
```
