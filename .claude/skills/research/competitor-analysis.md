# /competitor-analysis — 競合分析フロー

## 用途
競合他社を体系的に調査・分析し、差別化機会を特定する。

## 実行フロー
1. `competitor-agent` — 競合情報収集
2. `review-research-agent` — 競合のレビュー収集
3. `competitor-analyst` — データの定量分析
4. `pricing-analyst` — 価格比較分析
5. 総合的な示唆の整理

## 分析出力テンプレート
| 分析軸 | 自社 | 競合A | 競合B |
|------|-----|-----|-----|
| 価格帯 | | | |
| 強み | | | |
| 弱み | | | |
| 主要訴求 | | | |
| SEO強度 | | | |
| SNSフォロワー | | | |

## 差別化機会マトリクス
- 競合が弱く自社が強い領域 → 即時強化
- 競合が強く市場重要度が高い領域 → 戦略的投資
- どちらも弱い領域 → ブルーオーシャン機会
