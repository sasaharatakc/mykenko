# /citation-build — 引用獲得戦略

## 用途
権威サイトからMYKENKOへの引用・メンションを獲得するための施策を設計・実行する。

## 引用獲得チャネル
1. **PR・メディア掲載** — プレスリリース配信・記者へのピッチ
2. **ゲスト投稿** — 業界ブログ・メディアへの寄稿
3. **データ・調査レポート** — 独自データを公開して引用を誘発する
4. **専門家コメント** — メディアからの取材対応・HARO等の活用
5. **パートナーシップ** — 関連ブランド・インフルエンサーとの協力

## 高品質引用の基準
- DA（ドメインオーソリティ）: 40以上
- 関連性: EC・健康・美容・ライフスタイル分野
- リンクタイプ: dofollow（nofollow も価値あり）

## 月次目標
- 新規被リンク: 月10件以上
- DA40以上からの被リンク: 月3件以上
- ブランドメンション（リンクなし含む）: 月20件以上
