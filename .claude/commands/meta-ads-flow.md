# /meta-ads-flow — Meta広告運用フロー

## 用途
Facebook/Instagram広告の設計から最適化までのフローを実行する。

## キャンペーン構造
```
キャンペーン（目標：コンバージョン）
  └ 広告セット（ターゲット：類似オーディエンス）
       └ 広告（クリエイティブA）
       └ 広告（クリエイティブB）
```

## A/Bテスト設計
- 1要素ずつテストする（ターゲット or クリエイティブ）
- 最低サンプル: 50コンバージョン以上
- テスト期間: 7〜14日間

## 最適化の順序
1. CTR改善（クリエイティブ・コピーの改善）
2. ランディングページCVR改善
3. ターゲット精度改善（類似オーディエンスの最適化）
4. 入札戦略調整（CPA → ROAS目標への移行）
