# /evidence-search — エビデンス検索

## 用途
医療・健康コンテンツの根拠となるエビデンスを収集する。

## エビデンス収集手順
1. `academic-paper-agent` でPubMed・CiNii検索
2. エビデンスレベルを確認する
3. 最新（5年以内）の研究を優先する
4. 相反する研究も確認してバランスを取る

## エビデンスレベル（高い順）
1. システマティックレビュー・メタアナリシス
2. ランダム化比較試験（RCT）
3. コホート研究
4. 症例対照研究
5. 症例報告・専門家意見

## 引用表記
```
「〇〇の研究（2023年、XXX大学）によると...」
出典: [論文タイトル], [ジャーナル名], [DOI]
```
