# /ai-overview-optimize — Google AI Overview最適化

## 用途
検索結果のAI概要（SGE）に自社コンテンツを掲載させるための最適化を実施する。

## AI Overview掲載の条件
- 権威性の高いページ（E-E-A-T スコアが高い）
- 質問に対して明確な答えが冒頭にある
- 構造化データが正しく実装されている
- 引用しやすいファクト・数値・定義が含まれる

## 最適化チェックリスト
- [ ] 記事冒頭にBLUF（Bottom Line Up Front）形式で答えを置く
- [ ] FAQセクションを設ける（質問→答えの構造）
- [ ] 著者情報・専門家監修の明記
- [ ] 情報の鮮度（最終更新日の明示）
- [ ] 信頼できる外部ソースへのリンク
- [ ] HowTo・FAQ スキーマの実装

## コンテンツ最適化パターン
```markdown
## よくある質問: [質問文]
[冒頭で直接答える — 2〜3文]
[補足説明・詳細]
```
