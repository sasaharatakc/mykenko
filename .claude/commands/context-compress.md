# /context-compress — コンテキスト圧縮

## 用途
長い会話・大量のドキュメントを要約・圧縮して、コンテキストウィンドウを効率的に使用する。

## 圧縮プロセス
1. **重要度分類** — 情報を「必須・有用・削除可」に分類する
2. **要約生成** — 長い文章を核心だけに圧縮する
3. **構造化** — 箇条書き・テーブル形式で情報密度を上げる
4. **参照保持** — 詳細を削除した場合、参照先（ファイルパス・セクション）を残す

## 圧縮ルール
- コード例: 実行可能な最小サンプルに絞る
- 会話履歴: 決定事項・アクションアイテムのみ保持する
- 設計書: 現在の実装に関係する部分のみ保持する

## 出力フォーマット
```markdown
## サマリー（圧縮後）
[最重要情報を箇条書き]

## 省略した情報の参照
- 詳細設計: docs/design.md
- 過去の議論: Notion / GitHub Issue #123
```
