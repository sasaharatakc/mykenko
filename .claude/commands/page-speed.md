# /page-speed — ページ速度改善

## 用途
Core Web Vitalsの改善によってSEO順位とユーザー体験を向上させる。

## Core Web Vitals目標値
| 指標 | 良い | 要改善 | 悪い |
|-----|-----|------|-----|
| LCP（最大コンテンツ描画） | 2.5秒以内 | 4.0秒以内 | 4.0秒超 |
| INP（操作への反応） | 200ms以内 | 500ms以内 | 500ms超 |
| CLS（レイアウトシフト） | 0.1以下 | 0.25以下 | 0.25超 |

## 改善チェックリスト

### LCP改善
- [ ] ヒーロー画像をWebP/AVIFに変換する
- [ ] `fetchpriority="high"` でヒーロー画像を優先読み込みする
- [ ] CDNを使用してサーバーレスポンスを高速化する
- [ ] サーバーサイドレンダリング（SSR）でFCPを改善する

### CLS改善
- [ ] 画像に`width`/`height`属性を明示する
- [ ] フォントのfont-displayを`swap`に設定する
- [ ] 動的コンテンツの挿入はページ下部に限定する

### INP改善
- [ ] 長いJavaScriptタスクを分割する（>50msのタスクを検出する）
- [ ] イベントハンドラーで重い処理を`scheduler.postTask()`で延期する
