# /vendor-onboard — ベンダーオンボーディング

## 用途
新規ベンダー（出品者）のMYKENKOへの参加プロセスを最適化する。

## オンボーディングフロー
```
1. 申請・審査
   ↓
2. 契約・規約同意
   ↓
3. ショップ設定
   ↓
4. 商品登録（最初の1商品）
   ↓
5. テスト購入・確認
   ↓
6. 公開・販売開始
```

## ベンダー審査チェックリスト
- [ ] 本人確認書類の確認
- [ ] 商品の合法性確認（医療品・許可が必要な商品）
- [ ] 薬機法・景品表示法の説明・同意取得
- [ ] 手数料体系の説明
- [ ] 返品・返金ポリシーの確認

## オンボーディングKPI
- 申請→審査完了: 2営業日以内
- 審査承認→初出品: 7日以内
- 初出品→初売上: 30日以内
- 90日継続率: 70%以上

## よくある脱落ポイントへの対策
1. **商品登録が複雑** → 登録ウィザード・テンプレート提供
2. **価格設定が不安** → 類似商品の相場を表示する
3. **配送方法が分からない** → 推奨配送業者と設定手順を案内する
