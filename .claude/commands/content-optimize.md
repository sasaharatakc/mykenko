# /content-optimize — コンテンツ最適化

## 用途
既存コンテンツのSEOスコアを向上させるための改善を実施する。

## 最適化チェックリスト
- [ ] H1にメインキーワードが含まれるか
- [ ] 冒頭100文字にキーワードが自然に含まれるか
- [ ] キーワード密度が適切か（1〜3%）
- [ ] 関連キーワード・LSIキーワードが含まれるか
- [ ] 内部リンクが3個以上設置されているか
- [ ] 外部権威サイトへのリンクがあるか
- [ ] 画像にalt属性が設定されているか
- [ ] 文字数が競合上位ページ以上か

## リライト優先度
| スコア | 対応 |
|------|-----|
| 7-10位 | 小幅修正で効果大（最優先） |
| 11-20位 | コンテンツ拡充・内部リンク強化 |
| 圏外 | 大幅リライトまたは新規作成 |
