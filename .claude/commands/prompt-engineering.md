# /prompt-engineering — プロンプトエンジニアリング

## 用途
Claude/GPT等のLLMに対して効果的なプロンプトを設計する。

## プロンプト設計の原則
1. **明確な役割設定**: 「あなたは〇〇の専門家です」
2. **具体的な指示**: 出力形式・長さ・スタイルを明示する
3. **コンテキスト提供**: 背景情報・制約条件を与える
4. **例示**: Few-shotで期待する出力パターンを示す
5. **評価基準**: 良い回答の条件を明示する

## Chain of Thought（CoT）
```
「ステップバイステップで考えてください：
1. まず〇〇を確認する
2. 次に〇〇を分析する
3. 最後に〇〇を結論として述べる」
```

## System Promptのベストプラクティス
- ロール・制約・出力形式を明記する
- キャッシュ対象（静的）とユーザー入力（動的）を分ける
- 医療・法律等YMYLは「専門家に相談を」を必ず含める
