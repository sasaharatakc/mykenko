# /parallel-run — 並列実行

## 用途
独立したタスクを複数のAgentに同時実行させ、処理時間を最短化する。

## 並列化の判断基準
- タスク間に依存関係がない → 並列実行
- 一方の結果が他方の入力になる → 直列実行
- 同じリソースを同時に変更する → 直列実行（競合防止）

## 並列実行例
```
# 独立して実行できる調査タスク
並列: competitor-agent（競合A調査）+ market-research-agent（市場規模調査）

# 依存関係あり（直列）
keyword-agent（キーワード調査）→ seo-writer（記事執筆）
```

## 実行後の統合
各Agentの結果を収集し、矛盾や重複を整理してから最終出力を作成する。
