# /workflow-gen — ワークフロー生成

## 用途
複雑なプロジェクトや繰り返しワークフローを自動設計する。

## 生成プロセス
1. **ゴール定義** — 最終成果物と成功基準を明確にする
2. **タスク分解** — ゴールを達成するために必要なタスクを列挙する
3. **依存関係整理** — タスク間のINPUT/OUTPUTを整理する
4. **Agent割り当て** — 各タスクに最適なAgentを割り当てる
5. **スケジュール設計** — 実行順序と並列化を最適化する

## 出力形式
```
## ワークフロー: [プロジェクト名]
目標: [成果物の定義]

フェーズ1（並列実行）:
  - [Agent A] → [成果物A]
  - [Agent B] → [成果物B]

フェーズ2（直列実行）:
  - [Agent C] → [成果物C] ← 成果物A+Bを使用
```
