# /serp-deep-analysis — SERP詳細分析

## 用途
特定キーワードの検索結果を詳しく分析し、上位表示に必要な要件を把握する。

## 分析手順
1. キーワードで検索し、上位10件のURLを収集する
2. 各ページのコンテンツ形式・文字数・構成を分析する
3. 共通要素（見出し・FAQ・画像等）を特定する
4. SERPフィーチャー（Featured Snippet・PAA等）を確認する
5. 差別化できる余地を特定する

## 分析出力
```markdown
## SERP分析: [キーワード]
- 検索意図: [情報/比較/購買]
- 上位コンテンツ形式: [記事/LP/動画]
- 平均文字数: [X,000字]
- 必須要素: [FAQあり/比較表あり等]
- 差別化機会: [競合が対応していない視点]
```
