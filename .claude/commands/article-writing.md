# /article-writing — 長文記事執筆フロー

## 用途
SEO記事・解説記事・コラムなどの長文コンテンツを品質高く効率的に作成する。

## 執筆プロセス
1. **リサーチ** — 検索意図の確認・競合コンテンツ分析・情報収集
2. **アウトライン** — H1/H2/H3の構成を決定する
3. **ドラフト執筆** — アウトラインに沿って執筆する（速度優先）
4. **エディット** — 論理・文章・表現の改善
5. **SEO最適化** — キーワード・メタタグ・内部リンクを設定する
6. **コンプライアンスチェック** — 薬機法・景品表示法（健康コンテンツの場合）

## コンテンツ品質チェックリスト
- [ ] 検索意図を満たしているか
- [ ] E-E-A-T（経験・専門性・権威性・信頼性）を体現しているか
- [ ] 競合より詳しい・役立つ内容があるか
- [ ] 読者がすぐに行動できる具体的な情報があるか
- [ ] 内部リンクが3本以上設置されているか
- [ ] 医療・健康コンテンツの場合、免責事項があるか

## 見出し構成パターン
```
H1: [メインキーワード] + [価値提案]
H2: [課題・背景]
H2: [解決策の概要]
H2: [具体的な方法①②③]
H2: [よくある質問]
H2: [まとめ]
```
