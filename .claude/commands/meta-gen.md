# /meta-gen — メタタグ生成

## 用途
ページのコンテンツからSEO最適化されたタイトルタグ・メタディスクリプションを生成する。

## 生成ルール

### タイトルタグ
- 文字数: 28〜60文字
- 主要キーワードを前半に配置する
- ブランド名（MYKENKO）は末尾に「| MYKENKO」形式で付ける
- 重複タイトルは避ける

### メタディスクリプション
- 文字数: 70〜155文字
- 主要キーワードを自然に含める
- CTAを含める（「詳細はこちら」「今すぐチェック」等）
- 商品ページ: 価格・特徴・ベネフィットを含める
- カテゴリページ: 品揃えの豊富さと絞り込みのしやすさを訴求する

## 出力フォーマット
```
<title>キーワードを含む魅力的なタイトル | MYKENKO</title>
<meta name="description" content="検索意図に応えるディスクリプション。CTA含む。文字数目安: 120文字">
```
