# /security-review — セキュリティレビュー

## 用途
コード変更のセキュリティ問題を事前にチェックし、脆弱性を混入させない。

## レビューチェックリスト

### 認証・認可
- [ ] 全APIエンドポイントに適切な認証ミドルウェアが設定されているか
- [ ] 顧客/ベンダー/管理者の権限分離が正しいか
- [ ] JWTトークンの有効期限が適切か

### 入力値検証
- [ ] すべてのユーザー入力がバリデートされているか
- [ ] SQLクエリにEloquentまたはプリペアドステートメントを使用しているか
- [ ] HTMLエスケープが適切に行われているか（XSS対策）

### 機密情報
- [ ] APIキー・パスワードがコードにハードコードされていないか
- [ ] ログに機密情報が含まれていないか
- [ ] レスポンスに不要な内部情報が含まれていないか

### API
- [ ] レート制限が設定されているか
- [ ] CORS設定が適切か
- [ ] CSRFトークンが必要な操作に使用されているか
