# /campaign-launch — キャンペーン実行フロー

## 用途
MYKENKOのマーケティングキャンペーンを設計から実行まで一貫して管理する。

## 実行ステップ
1. **キャンペーン設計** — 目標・ターゲット・予算・期間・KPIを定義する
2. **クリエイティブ制作** — バナー・LP・広告コピー・メールを作成する
3. **薬機法チェック** — 健康・美容商品の場合は必ずコンプライアンス確認
4. **チャネル設定** — 広告アカウント・メール配信・SNSの設定を行う
5. **ランディングページ準備** — LP・商品ページの最終確認
6. **配信開始** — スケジュール通りに配信を開始する
7. **モニタリング** — 配信初日から指標を監視し、異常があれば即対応
8. **最適化** — A/Bテスト結果・CPAを見て予算配分を最適化する

## キャンペーン別担当Agent
| キャンペーン種別 | 主担当Agent |
|------------|-----------|
| Meta広告 | meta-ads-agent |
| SEO・コンテンツ | seo-writer + keyword-agent |
| メール配信 | email-marketing-agent |
| SNS投稿 | sns-writer |
| LP改善 | lp-designer + conversion-agent |
