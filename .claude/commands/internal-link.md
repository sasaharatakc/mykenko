# /internal-link — 内部リンク最適化

## 用途
サイト内の内部リンク構造を最適化し、クロール効率とページ権威の流れを改善する。

## 内部リンク設計の目的
1. **クロール効率** — 検索エンジンが全ページを効率よくクロールできるようにする
2. **権威分配** — 強いページから弱いページへPageRankを流す
3. **ユーザー体験** — 関連コンテンツへの自然な誘導

## 内部リンク設計原則
- 重要なページへは3クリック以内でアクセスできるようにする
- トップページ→カテゴリページ→詳細ページの階層構造を維持する
- アンカーテキストは「こちら」「詳細」ではなくキーワードを含む文章にする
- 関連記事・関連商品リンクを各ページに設置する

## チェックリスト
- [ ] 孤立したページ（内部リンクが0のページ）がないか
- [ ] 重要ページへの内部リンク数が十分か（最低3〜5本）
- [ ] アンカーテキストにキーワードが含まれているか
- [ ] ページの深さが3クリック以内か
- [ ] nofollow が不必要に設定されていないか
