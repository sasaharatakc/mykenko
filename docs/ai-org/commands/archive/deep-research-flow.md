# /deep-research-flow — 深層リサーチフロー

## 用途
テーマについて多角的・体系的に深く調査し、インサイトを導出する。

## 実行フロー
1. `google-search-agent` — 概要・一般情報収集
2. `news-agent` — 最新動向収集
3. `reddit-agent` — ユーザーの本音収集
4. `academic-paper-agent` — エビデンス・研究収集（必要な場合）
5. `competitor-agent` — 競合状況調査
6. `market-analyst` — データ統合・分析

## 出力フォーマット
```markdown
## 調査サマリー
[3〜5行の核心]

## 主要発見
1. [発見] ← [ソース]

## 事業への示唆
- [アクション可能なインサイト]

## 不確実な情報・調査の限界
```
