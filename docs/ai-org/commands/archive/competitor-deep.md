# /competitor-deep — 競合深層分析

## 用途
競合の戦略・プロダクト・マーケティング・財務を深く分析し、差別化機会を特定する。

## 分析フレームワーク

### 4P分析
| 要素 | 競合A | 競合B | 自社 |
|-----|-----|-----|-----|
| Product（製品） | - | - | - |
| Price（価格） | - | - | - |
| Place（流通） | - | - | - |
| Promotion（販促） | - | - | - |

### Jobs-to-be-Done分析
競合ユーザーが「何のために」そのサービスを使っているかを分析する。
- 機能的ジョブ: 何を達成したいか
- 感情的ジョブ: どう感じたいか  
- 社会的ジョブ: 他者にどう見られたいか
