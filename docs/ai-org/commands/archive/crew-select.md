# /crew-select — Crew選定

## 用途
依頼内容から最適なCrewとAgentの組み合わせを選定する。

## 選定フロー
1. タスクのドメインを特定する（技術/ビジネス/クリエイティブ）
2. 必要な専門性をリストアップする
3. 各Crewの担当範囲と照合する
4. 主担当Crewと支援Crewを決定する
5. 具体的なAgent名を指定する

## 注意事項
- 複数Crewが必要な場合は依存関係を明示する
- 1タスクに最大3Agentまで（それ以上は分割を検討）
- 戦略タスクはkingmaker/gamechanger → ceo-agent → 実行Agentの順で処理する
