# /priority-sort — 優先度ソート

## 用途
複数のタスク・課題・施策を優先度順に並べ替えて実行順序を決定する。

## 優先度評価フレームワーク

### ICEスコア
```
ICE = Impact（影響度）× Confidence（確信度）× Ease（実施容易性）
各指標: 1〜10点
```

### PIEスコア
```
PIE = Potential（改善ポテンシャル）× Importance（重要度）× Ease（実施容易性）
各指標: 1〜10点
```

### MoSCoW法
- **Must Have**: 必須（なければリリース不可）
- **Should Have**: 重要（可能な限り含める）
- **Could Have**: あれば良い（時間があれば）
- **Won't Have**: 今回は対象外

## 優先度ソートの出力フォーマット
```markdown
## 優先タスク一覧

| 順位 | タスク | ICEスコア | 理由 |
|-----|------|---------|-----|
| 1 | ... | XX | ... |
```
