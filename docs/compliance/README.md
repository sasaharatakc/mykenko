# Compliance Docs

薬機法・景表法・医療広告ガイドラインへの対応ドキュメント。

## 基本方針

- **薬機法**: 医薬品・医療機器等の品質、有効性及び安全性の確保等に関する法律
- **景表法**: 不当景品類及び不当表示防止法
- **医療広告ガイドライン**: 厚生労働省の医療広告ガイドライン

## 禁止表現（代表例）

| 禁止 | 理由 | 代替表現 |
|------|------|---------|
| 「必ず治る」 | 効果保証 | 「一般的な情報として」 |
| 「副作用なし」 | 虚偽表示 | 「個人差があります」 |
| 「医師いらず」 | 医療行為勧奨 | 「医師・薬剤師にご相談ください」 |
| 「〇〇を治療」 | 医療広告 | 「〇〇に関する情報」 |

## 必須免責表示

全医療情報ページの末尾に `MedicalDisclaimer` コンポーネントを必須表示。
`packages/ui/src/components/Disclaimer.tsx` を参照。
