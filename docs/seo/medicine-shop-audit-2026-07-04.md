# medicine.shop SEO監査レポート（2026-07-04）

## 監査概要
- 対象URL: https://medicine.shop/
- 依頼内容: SEO総合監査 + 「お薬ショップ」等の検索に出てこない原因調査
- 関連Issue: #36（Epic）, #40, #41, #42, #43, #44, #46, #48
- 監査方法: WebFetch / curl による直接アクセス、Google検索（`site:` 演算子含む）、Wayback Machine、リポジトリ内コード調査
- 制約: `https://medicine.shop/` への直接アクセスは HTTP 403（WebFetch・curl 双方）で終始ブロックされ、robots.txt / sitemap.xml も同様に取得不可だった。そのため本レポートの一部項目は「未検証」として扱う。

## 0. 最優先の前提確認（Critical）

**発見事実**
1. GitHub Issue（#36, #40, #42, #46, #48）は `medicine.shop` を自社の医薬品個人輸入代行サイト（日本市場向け、`language_code=ja` / `location_code=2392`=Japan）として、SEO診断・キーワード設計・コンプライアンスチェックの対象に設定している。
2. しかし `site:medicine.shop` のGoogle検索結果は、インド・Navi Mumbai拠点の健康雑貨EC事業者（ACCUSURE姿勢矯正ベルト、DABURシャンプー、TYNOR膝サポーター、ROMSONS血圧計、PIGEON乳幼児用品など）の英語商品ページのみで構成されている。日本語コンテンツ・個人輸入関連ページは一切ヒットしない。
3. 「お薬ショップ」「medicine.shop 個人輸入」等の日本語検索を行っても、日本の個人輸入代行サイト一覧（オオサカ堂・お薬なび・ライフパートナー・お薬堂など）の中に `medicine.shop` は登場しない。
4. 「medicine.shop 特定商取引法」で検索しても該当ページが見つからない。日本向けECサイトには特定商取引法に基づく表記が法的に必須であり、通常は最もインデックスされやすいページの一つである。
5. `apps/price-monitor/scrape_medicine.js` のコメントには「VPN未接続でテスト」「SKIP_IP_CHECK」という記述があり、地域制限（ジオブロック）またはBot対策（Cloudflare等）でのアクセス制御が既知の課題として扱われている。
6. リポジトリ内の共通SEOツール（`packages/seo/src/meta.ts`, `sitemap.ts`）は base URL を `https://mykenko.jp` に固定しており、`medicine.shop` 用のコードはこの monorepo に一切含まれていない（別基盤で運用されている外部サイトと考えられる）。

**結論**
現在 Google にインデックスされ、外部から観測できる `medicine.shop` は、御社が想定している日本語個人輸入サイトのコンテンツと一致していない。ドメインの所有権移転やDNS切り替えが未完了である、または新コンテンツが本番反映されていない可能性が高い。この点の解消が最優先（Critical）。

## 「お薬ショップ」で検索しても出てこない理由（結論）

現時点の証拠を総合すると、最も可能性が高い理由は次の通り：

> **`medicine.shop` は日本語の個人輸入代行サイトとしてGoogleにまだ認識されていない。** Google上で観測できる同ドメインの内容は、インド拠点の無関係な健康雑貨ECの英語コンテンツであり、日本語ページ・特定商取引法表記・個人輸入関連コンテンツが一件も存在しない。加えてサイト自体が現在403でクロールを拒否する状態にあり、これがGooglebotにも適用されている場合、新しい日本語コンテンツを公開してもインデックスされない。

つまり「順位が低い」のではなく、**そもそも検索エンジンに正しい姿で認識されていない**状態。SEOの文言・キーワード最適化以前に、以下の技術的な土台を直す必要がある。

### 解決策（実行順）
1. DNS・ホスティング・WAF設定を点検し、正しい本番コンテンツが `medicine.shop` で配信され、かつGooglebot（および一般ユーザー）が403でブロックされていないことを確認する。
2. Google Search Console でプロパティを検証し、URL検査ツールで実際にGoogleが取得しているHTMLを確認する。403が解消したら「インデックス登録をリクエスト」する。
3. 特定商取引法表記・会社概要など、日本のECサイトとして最低限必要な法定ページを本番に実装する。
4. Issue #42（Product SEO Agent）の診断項目に沿って、商品ページに日本語のtitle/H1/成分情報/個人輸入注意点/FAQ/構造化データを実装する。
5. Issue #43（Compliance Agent）で薬機法・景表法上のNG表現がないかチェックしてから公開する。
6. サイトマップを生成しSearch Consoleに送信、内部リンクで主要ページ間を接続する。
7. 上記1〜3が完了して初めて、キーワード最適化・コンテンツ拡充・競合比較（Issue #46）などの「順位を上げる」施策が意味を持つ。

## 監査の限界・免責事項
- 本レポートはGooglebot以外の外部アクセス（WebFetch/curl）が403でブロックされた状態での調査結果である。自社のオフィス回線や管理画面からアクセスした場合は異なる内容が表示される可能性があるため、必ず社内から直接目視確認してほしい。
- 「未検証」と記載した項目は、リスクが無いことを意味しない。アクセスブロックが解消次第、再監査を推奨する。
